# Classic Iris Flower Classification using Machine Learning

## Overview

The Iris dataset is one of the most famous datasets in machine learning. It is used to classify iris flowers into their species based on petal and sepal measurements.

This project demonstrates a complete beginner-friendly classification workflow using the Iris dataset and compares multiple machine learning models.

---

## Problem Statement

The goal is to classify iris flowers into the correct species using numerical measurements.

This is a classic supervised learning problem and is widely used to understand how classification works.

---

## Solution

This notebook:
1. loads the Iris dataset
2. explores the data visually
3. prepares the features
4. trains multiple classification models
5. compares their performance
6. makes a sample prediction

---

## Dataset

The dataset contains 150 rows and 6 columns.

### Input Features
- SepalLengthCm
- SepalWidthCm
- PetalLengthCm
- PetalWidthCm

### Target Variable
- Iris species

---
